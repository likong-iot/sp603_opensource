自动采集模式说明：
1. 寄存器地址分布：0-49000 为映射从机数据，49001-49060 为错误标志位。
2. 映射行为：映射范围内可任意长度读取；写入映射范围将转发到对应真实从机。
3. 读取失败处理：若对应条目通信异常，读取返回 0。
4. 错误标志位：49001-49060 对应条目 1-60；正常返回 1，异常返回该条目的错误标记值。
