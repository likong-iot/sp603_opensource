# SP603-多串口物联网网关

## 指示灯状态

面板 LED 经过 ULN2003 驱动，GPIO 高电平表示点亮。网络指示灯由网络管理器根据当前链路角色统一控制，串口数据灯单独表示串口收发活动。

| 指示灯 | 对应功能 | 常亮 | 慢闪 | 熄灭 | 异常闪烁 |
| --- | --- | --- | --- | --- | --- |
| LAN | W5500 以太网 | 当前实际主上网接口 | 已启用且链路可用，但不是当前主上网接口，或作为下行网络提供服务 | 未启用 | 初始化失败，250 ms 亮 / 750 ms 灭 |
| WIFI | Wi-Fi STA/AP 共用 | Wi-Fi STA 是当前实际主上网接口，且 AP 未提供下行服务 | AP 正在提供服务，或 Wi-Fi STA 已连接但不是当前主上网接口 | 未启用 | 初始化失败，250 ms 亮 / 750 ms 灭 |
| 4G | AIR780E 4G | 4G 是当前实际主上网接口 | 4G 已启用且可用但不是当前主上网接口，或正在等待拨号/IP | 未启用 | 初始化失败，250 ms 亮 / 750 ms 灭 |

网络慢闪为 1 秒亮、1 秒灭。只有当前被 esp_netif_set_default_netif() 选中的上行接口常亮；备用接口获得 IP 后保持慢闪。接口切换时，常亮灯会随活动上行接口改变。

Wi-Fi STA 和 AP 共用 WIFI 灯。当 Wi-Fi STA 同时作为当前上网接口、且 AP 同时作为下行网络提供服务时，WIFI 灯使用组合节奏：250 ms 亮、250 ms 灭、250 ms 亮、1.25 s 灭，循环一次为 2 秒。该双脉冲表示“Wi-Fi 客户端上网 + Wi-Fi 热点提供网络”同时成立。

### SYS 系统运行灯

SYS 不表示网络连接，只表示系统自身状态。不同状态使用不同频率，便于在没有串口日志时判断系统状态。

| 状态 | 灯效 | 说明 |
| --- | --- | --- |
| 启动中 | 2.5 Hz，200 ms 亮 / 200 ms 灭 | 系统组件尚未完成初始化 |
| 正常运行 | 1 Hz，500 ms 亮 / 500 ms 灭 | 系统初始化完成，网络服务和工作模式正常 |
| 警告 | 0.5 Hz，200 ms 亮 / 1.8 s 灭 | 配置的网络接口启动失败，或没有可用的主上网接口 |
| 严重错误 | 4 Hz，125 ms 亮 / 125 ms 灭 | 不可恢复的系统错误 |

### 串口数据灯

COM1、COM2、RS232 三个灯只在对应串口发生收发活动时点亮，活动结束后保持约 100 ms。双 RS485 模式下分别对应 COM1/RS485-1、COM2/RS485-2 和 RS232；RS422 模式下 COM1 灯表示发送、COM2 灯表示接收。
